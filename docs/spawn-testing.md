# Jak vytvořit předměty u postavy

- V r2modman otevři profil **MoreScrapItems-Dev** a soubor `BepInEx/config/danielsitek.more-scrap-items.cfg`.
- V části `[Development]` nastav `SpawnInShipForTesting = true` a `RunHoldingTest = false`.
- Spusť hru přes **Start modded** a založ místní hru jako **Host**. Po několika sekundách se všechny tři předměty objeví u postavy.
- Po kontrole nastav `SpawnInShipForTesting = false`.
